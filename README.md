## О проекте
Данный репозиторий создан в рамках дисциплины «Жизненный цикл разработки программного обеспечения».  
Проект представляет собой настольное приложение на JavaFX, которое пересчитывает введённое пользователем время ожидания (в минутах) в субъективные бытовые ситуации: очередь в поликлинике, загрузка Windows, ожидание доставки еды, прогрев микроволновки.  
Приложение демонстрирует архитектуру MVC с активной моделью, модульную систему JPMS и сборку Maven.

## Функциональность
- Ввод времени ожидания через отдельное модальное окно.
- Автоматическое сохранение последнего введённого значения.
- Пересчёт времени с использованием коэффициентов субъективного восприятия.
- Отображение результатов в главном окне.
- Проверка корректности ввода (отрицательные числа, текст, пустые строки) с выводом сообщения об ошибке.

## Технологии
- **Язык:** Java 17+
- **GUI:** JavaFX
- **Сборка:** Maven
- **Модульность:** JPMS (`module-info.java`)
- **Архитектура:** MVC (активная модель, `Observable`/`Observer`)

## Структура проекта
- `src/main/java/com/example/timeconverter/` — исходный код
  - `App.java` — точка входа
  - `model/TimeModel.java` — модель данных
  - `view/MainView.java`, `view/InputView.java` — представления
  - `controller/TimeController.java` — контроллер
- `src/main/resources/` — ресурсы
- `pom.xml` — конфигурация Maven
- `module-info.java` — описание модуля
